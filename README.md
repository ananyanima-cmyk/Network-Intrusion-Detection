# Network Intrusion Detection System

A Machine Learning-based Network Intrusion Detection System built using Python and Streamlit.

## Features
- Detects potentially malicious network traffic from uploaded CSV files.
- Uses a trained Machine Learning model for prediction.
- Displays prediction results through a Streamlit interface.

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Joblib

## How to Run
1. Install the required libraries using `pip install -r requirements.txt`.
2. Run the application using `streamlit run app.py`.
